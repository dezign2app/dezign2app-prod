# Desktop App Setup

Follow these steps to configure, run, and package the Dezign2App desktop application.

---

## 1. Prerequisites

- **Node.js** >= 20.0
- **pnpm** >= 10.4.1
- **Docker Desktop** (running, for local container execution)
- **Windows Build Tools** (on Windows, for `node-pty` native compilation):
  ```powershell
  npm install --global windows-build-tools
  ```

---

## 2. Install Workspace Dependencies

From the workspace root:

```bash
pnpm install
```

---

## 3. Running in Development

To start both the Next.js dev server and the Electron shell:

```bash
pnpm desktop:dev
```

Alternatively, run in two separate terminals:
```bash
# Terminal 1: Start web app on port 46500
pnpm --filter web dev

# Terminal 2: Start Electron window
pnpm --filter desktop dev
```

---

## 4. Packaging for Production

To compile Next.js in production mode and package desktop executables for Windows, macOS, and Linux:

```bash
# Package for all platforms (Windows, macOS, Linux)
pnpm build:desktop

# Or package for specific target platforms:
pnpm build:desktop:win     # Windows (.exe)
pnpm build:desktop:mac     # macOS (.dmg, .zip)
pnpm build:desktop:linux   # Linux (.AppImage, .tar.gz)
```

The packaged executables will be generated in `apps/desktop/release/`:
```
apps/desktop/release/
├── win-unpacked/Dezign2App.exe
├── Dezign2App-Setup-*.exe
├── Dezign2App-*.dmg
└── Dezign2App-*.AppImage
```
